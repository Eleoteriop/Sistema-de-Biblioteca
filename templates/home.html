Sobre o projeto Biblioteca

O projeto Biblioteca foi desenvolvido com o objetivo de criar uma plataforma simples para facilitar o acesso aos livros e o gerenciamento de empréstimos. Através da plataforma, os usuários podem realizar seu cadastro, acessar sua conta, consultar os livros disponíveis, solicitar empréstimos e acompanhar suas leituras.

Para a construção do sistema, foram utilizadas tecnologias como Python, Flask, SQLite, HTML e CSS, além da integração com a API da Open Library para consulta e exibição dinâmica de informações sobre livros. O desenvolvimento permitiu aplicar conceitos de criação de rotas, gerenciamento de dados, integração com serviços externos e construção de uma interface web funcional.
